## Conventions

- **Sign-in.** Personal access tokens (AUTH-6) come first. OAuth paths follow once a developer key exists (PRD 4.1).
- **Data.** All server data goes through `src/canvas/`: the client, endpoint modules, and React Query hooks keyed by account. Screens never call `fetch` directly.
- **Testing without a real account.** `pnpm run fake-canvas` serves a fake Canvas at `http://localhost:3030`. Sign in with domain `localhost:3030` and token `dev`. Feature endpoints live in `devtools/fake-canvas/routes/<feature>.mjs`.
- **First-build acceptance means:**
  - typecheck and lint pass
  - the screen works against the fake Canvas on iOS and Android
  - it works in light and dark mode
  - accessibility and localization acceptance are deferred as specified above
